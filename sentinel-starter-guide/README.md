# Sentinel starter guide

A single-file, tabbed HTML guide to operationalizing Microsoft Sentinel, from onboarding to advanced automation. **[View it live on GitHub Pages.](https://carolinemutua.github.io/sentinel/sentinel-starter-guide/)** Or open `index.html` in any browser locally. Nothing needs to be installed.

## What it covers

Five tabs:

- **Getting Started** — plan a Log Analytics workspace, onboard Sentinel, connect data, install Content Hub solutions.
- **Use Cases** — worked detection scenarios (impossible travel, deprovisioning gaps) mapped to the data pipeline.
- **Rules and Automation** — summary rules, analytic rules, automation rules, playbooks, and AI-generated playbooks, and how they chain together.
- **Sentinel Platform** — the wider platform: data lake, graphs, UEBA, threat intelligence, and the MCP server for AI-driven investigation.
- **Resources and Pricing** — pricing model, calculators, and cost-by-capability, all from public Microsoft pages.

## Source and scope

The content is drawn from public [Microsoft Learn](https://learn.microsoft.com/azure/sentinel/) documentation and other public Microsoft sources. It is a personal learning and reference guide, not official guidance. For specific pricing, use the official Microsoft pricing pages linked inside.
